Layout Props

Component: Layout
Source: src/components/Layout/Layout.tsx

Expected props:
- children (required): ReactNode content wrapped by the layout container.
- margin (optional): "xs" | "sm" | "md" | "lg" | "xl".
  Default: "md".
  Controls horizontal inner padding so content is not edge-to-edge.
- contentWidth (optional): "xs" | "sm" | "md" | "lg" | "xl".
  Default: "lg".
  Controls max width of the centered content area.
- sx (optional): style override object applied before `style`.
- class (optional): additional class string merged with `className`.

Inherited props:
- All standard div HTML attributes are supported via HTMLAttributes<HTMLDivElement>.
- Common examples: id, className, style, data-* attributes, aria-* attributes.

Notes:
- Layout uses the theme text color and a transparent background so the parent page background shows through.
- `style` and other HTML props are applied to the inner constrained content wrapper.
