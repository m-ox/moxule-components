Card Props

Component: Card
Source: src/components/Card/Card.tsx

Expected props:
- children (required): ReactNode rendered inside the card.
- color (optional): applies another theme's surface/text tokens.
- appearance (optional): visual treatment for card chrome.
	- solid (default): flat filled surface with no border or shadow.
	- outline: legacy transparent appearance with no border or shadow.
	- none: no border or fill, content-only container.
- sx (optional): style override object applied before `style`.
- class (optional): additional class string merged with `className`.

Inherited props:
- Standard HTML attributes for HTMLElement are supported via HTMLAttributes<HTMLElement>.
- Common examples: id, role, className, style, data-* attributes, aria-* attributes.

Notes:
- Card renders as an <article> element.
- Uses theme surface and text tokens by default. All appearances are borderless and shadowless.
- Opposite corners alternate between tighter and softer rounding: 4px 18px 4px 18px.
  Customize --mx-panel-radius in CSS to override.
